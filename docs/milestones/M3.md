# M3: Task Management UI

## Status: COMPLETE

## What Changed

### Frontend
- **`App.tsx`**: Task board with sections (Today Timed, Today Untimed, Legacy, Future), quick add, lifecycle actions.
- **`TaskRow.tsx`**: Task row with complete/undo/cancel/restore/delete/reschedule/edit actions.
- **`api.ts`**: Tauri invoke wrappers for all task commands.
- **`types.ts`**: TypeScript types mirroring Rust domain.
- **`App.test.tsx`**: 22 integration tests covering board rendering, quick add, edit, reschedule, lifecycle actions.
- **`styles.css`**: Task board and row styling.

### Rust
- **`lib.rs`**: Tauri commands for `list_board`, `create_task`, `update_task`, `reschedule_task`, `complete_task`, `undo_completion`, `cancel_task`, `restore_canceled_task`, `soft_delete_task`.
- **`app/mod.rs`**: `TaskService` with all use cases, `CreateTaskCommand`, `UpdateTaskCommand`.
